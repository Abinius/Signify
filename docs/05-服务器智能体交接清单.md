## 2. 部署步骤（宝塔 / 传统服务器）

```bash
cd /www/wwwroot/signify

# 1. 拉取最新代码
git pull

# 2. 安装依赖（⚠️ 见 §4 坑 1，Composer ≥2.10 需先关闭公告拦截）
composer install --no-dev --optimize-autoloader --ignore-platform-req=ext-fileinfo

# 3. 运行迁移（本次会应用全部待执行迁移，含 000001~000004）
php artisan migrate --force

# 4. 刷新配置缓存
php artisan config:cache
php artisan route:cache        # 可选，建议

# 5. 目录权限
chown -R www:www /www/wwwroot/signify
chmod -R 755 /www/wwwroot/signify/storage
chmod -R 755 /www/wwwroot/signify/bootstrap/cache
```

> `.env` 需包含（未变）：`APP_URL`、`DB_*`、`FILESYSTEM_DISK=public`、`SESSION_DRIVER=file`。

## 4. 部署关键坑（务必先读）

### 坑 1 ⚠️ Composer 安全公告拦截（会直接导致部署失败）
`laravel/framework ^11.0` 在 **Composer ≥2.10** 下默认被 security advisories 拦截（Laravel 11 已 EOL）。服务器执行 `composer install` 会报 "Your requirements could not be resolved… affected by security advisories"。

**解决（服务器一次即可，全局）：**
```bash
composer config --global policy.advisories.block false
composer install --no-dev --optimize-autoloader --ignore-platform-req=ext-fileinfo
```
> 此为部署环境的权衡决定；生产安全建议后续升级 Laravel 12。

### 坑 2 缺 fileinfo
生产服务器无 fileinfo。`AvatarService` 已用扩展名白名单 + GD 校验兜底，无需开启；`composer install` 需 `--ignore-platform-req=ext-fileinfo`。

### 坑 3 零构建
服务器**不要**跑 `npm run build`。本次所有新 CSS 类已由工作站在 `public/css/app.css` 编译好并入库。

### 坑 4 图片存储
头像/形象照/二维码存 `storage/app/public/*`（avatars / portraits / qrcodes），`public/storage` 软链已建。裁剪在浏览器完成，服务器只存最终图。

### 坑 5 分享卡 og 标签依赖绝对 URL
`og:image` 等基于 `APP_URL`。服务器 `.env` 的 `APP_URL` 必须为线上完整地址（微信爬虫不认相对路径）。

### 坑 6 抖音图标为占位
开源图标库均无抖音官方字形，`public/icons/douyin.svg` 用的是 TikTok 风格音符占位。如有官方 Douyin SVG 可直接替换同名文件，无需改代码。
