## 1. P1 — Signify 工作台骨架

> 目标：approved 企业家登录后能浏览双轨报告、brief/full 切换、文件缺失不崩。
> 用 fixture JSON 开发，不依赖 P2 产出。

### P1.0 前置：fixture 数据（0.25 日）
- **产出**：`storage/app/lantai/reports/20261027-20261102/report-brief.json` + `report-full.json`，手写两份符合 §4 schema 的 JSON（title/summary/domains/regions/content_md 都填真值，content_md 用兰台现有月报 markdown 片段）。
- **依赖**：无。
- **验收**：两份 JSON 能被 `json_decode` 正确解析。

### P1.1 Markdown 渲染依赖（0.25 日）
- **产出**：`composer require league/commonmark`；在 `config` 或 `App\Support` 封一个 `markdown_to_html(string): string`（转 HTML + XSS 兜底：`<script>` 等剥离）。
- **依赖**：无。
- **说明**：Signify 现无任何 Markdown 渲染能力；`content_md` 是原始 Markdown 含 `<details>`，必须服务端转 HTML。
- **验收**：`markdown_to_html("## 标题\n<details>…")` 输出含 `<h2>` 与折叠 `<details>`。

### P1.2 城市映射表（0.5 日）
- **产出**：`config/lantai_regions.php`，键=城市常见写法（「深圳」「深圳市」），值=省级裸名（「广东」）。覆盖 4 直辖市 + 15 副省级 + 27 省会，其余回退原值。
- **依赖**：兰台 `regional/constants.py` 的 PROVINCES / MUNICIPALITIES / SUB_PROVINCIAL（已核）。
- **验收**：`config('lantai_regions')['深圳'] === '广东'`；未命中城市回退逻辑可测。

### P1.3 LantaiReportService（1 日）
- **产出**：`app/Services/LantaiReportService.php`：
  - `list(): array` — glob `storage/app/lantai/reports/*/report-brief.json`，读 meta（不读 content_md），按 period 降序。
  - `find(string $period): ?array` — 读 brief + full 两份，返回 `['period','brief_md','full_md','meta']`。
  - `matchesEntrepreneur(array $meta, Entrepreneur $e): bool` — §8.3 规则（全国 / 省级裸名命中 / 城市回退）。
  - JSON 损坏 / 文件缺失 → 抛 `LantaiReportNotFoundException`。
- **依赖**：P1.0 fixture。
- **验收**：`list()` 返回 fixture 那期；`find('20261027-20261102')` 返回双轨；`find('不存在')` 返回 null。

### P1.4 访问中间件 + 路由 + 控制器（0.75 日）
- **产出**：
  - `app/Http/Middleware/WorkbenchAccess.php`：`auth` + `entrepreneur` 存在且 `status === 'approved'`；否则 403 或重定向个人中心带提示。
  - `routes/web.php` 加 workbench 路由组（§9.1）。
  - `app/Http/Controllers/WorkbenchController.php`：`index`（list + matchesEntrepreneur 分「与我相关」/「全部」）、`show`（find + 传 brief/full）。
- **依赖**：P1.3。
- **验收**：approved 用户进 `/workbench` 200；pending/rejected/游客被挡；`/workbench/report/{period}` 路由生效。

### P1.5 视图 + Alpine 切换（1 日）
- **产出**：
  - `resources/views/workbench/index.blade.php`：列表，每条 period/title/summary/regions 标签 + 「与我相关」「全部」tab。
  - `resources/views/workbench/show.blade.php`：brief/full 切换（Alpine `x-data="{track:'brief'}"`），`{!! markdown_to_html($brief_md) !!}`；full 默认隐藏 + `<details>` 折叠。
  - 复用 `layouts/app.blade.php`。
- **依赖**：P1.1（markdown）、P1.4（控制器）。
- **验收**：切换瞬时无刷新；full 的 `<details>` 默认折叠可点开；核验附录段落可见。

### P1.6 入口（0.25 日）
- **产出**：个人中心 `/my/profile` 或顶部导航，对 approved 企业家显示「工作台」链接；其他身份不显示。
- **依赖**：P1.4。
- **验收**：approved 看到入口、点击进 `/workbench`；pending 看不到。

### P1.7 Feature 测试（1 日）
- **产出**：`tests/Feature/WorkbenchTest.php`：
  - 访问门槛（4 身份：游客/pending/rejected/approved + 管理员）。
  - 列表「与我相关」过滤（city→省级裸名命中、「全国」可见、不命中不进默认视图）。
  - 详情 brief/full 都渲染、`period` 不存在 404、JSON 损坏不 5xx。
- **依赖**：P1.0–P1.6 全完。
- **验收**：全绿。

**P1 合计 ≈ 5 工作日。**

## 2. P2 — Python 对接

> 目标：双轨 cron 产出两份 `report-{kind}.json`，落到 Signify storage；LLM provider 接口铺路换模型。
> 与 P1 并行，不互相等待。

### P2.1 run.py 写盘带 kind（0.25 日）
- **产出**：`pipeline/run.py:174-175` 改 `report-{kind}.md` / `report-{kind}.json`。
- **依赖**：无。
- **验收**：`--mode brief` 产 `report-brief.json`；`--mode full` 产 `report-full.json`；不再互相覆盖。

### P2.2 DATA_DIR 读 env（0.25 日）
- **产出**：`pipeline/config.py` `DATA_DIR = Path(os.getenv('LANTAI_DATA_DIR', <现有默认>))`。
- **依赖**：无。
- **验收**：设 `LANTAI_DATA_DIR=/tmp/x` 后产物落 `/tmp/x/{period}/`。

### P2.3 LLM provider 接口（1 日）
- **产出**：`pipeline/llm.py` 抽 `LLMProvider` 抽象 + `SenseNovaProvider`（现有逻辑搬入）+ env 选 provider（`LANTAI_LLM_PROVIDER`，默认 sensenova）。保留 `chat_json()` 模块级函数作为 facade 调用当前 provider，调用方零改动。
- **依赖**：无。
- **验收**：默认行为与改前一致（现有测试全绿）；`LANTAI_LLM_PROVIDER=stub`（加一个返回固定 JSON 的 stub provider）能跑通 P5。

### P2.4 cron 双轨脚本（0.25 日）
- **产出**：`scripts/lantai-cron.sh`：先 `--mode brief`，后 `--mode full --republish`；设 `LANTAI_DATA_DIR` 指向 Signify storage。
- **依赖**：P2.1、P2.2。
- **验收**：一次跑产两份文件，`--republish` 不重跑 P2/P3/P4/P2.5（看 run.log 确认）。

### P2.5 本地产出 + 灌入（0.5 日）
- **产出**：用兰台现有 30 天台账（`pipeline/data/` 已有 raw）`--republish` 出双轨，落到 Signify `storage/app/lantai/reports/`。
- **依赖**：P2.1、P2.2、P2.3。
- **验收**：Signify `LantaiReportService::list()` 能读到该期。

### P2.6 Python 测试回归（0.25 日）
- **产出**：跑现有 166 测试 + test_publish 双轨用例。
- **依赖**：P2.1、P2.3。
- **验收**：全绿（契约未动，预期零失败）。

**P2 合计 ≈ 2.5 工作日。**

## 5. 关键路径与风险

**关键路径**：P1.0 → P1.1 → P1.3 → P1.4 → P1.5 → P1.7 → M3 → M4（约 5.5 日）。P1.2、P1.6 可插空。P2 整条并行，只要在 M3 前完成 P2.5 灌入即可。

**风险点**：

| 风险 | 影响 | 缓解 |
|---|---|---|
| Markdown 渲染 XSS | `content_md` 来自 LLM，含恶意标签 | P1.1 渲染层剥 `<script>`/`on*=`；`content_md` 只来自兰台可控源，非用户输入，风险可控 |
| `matchesEntrepreneur` 城市回退漏 | 企业家看不到相关报告 | P1.2 映射表覆盖副省级+省会，未命中回退「全国」可见；P1.7 测覆盖 |
| `--republish` 行为漂移 | 双轨 full 复用失败 → 重跑全流水线 | P2.4 看 run.log 确认跳过 P2/P3/P4；P2.6 回归 test_publish |
| sensenova 裸跑质量 | 错误判断直达企业家 | M4 前人工抽审几期；核验附录为空时告警；P3 换模型 |
| 读半写 JSON | `find()` 读到不完整文件 | `json_decode` 失败 → 抛异常 → 404，不 5xx |
